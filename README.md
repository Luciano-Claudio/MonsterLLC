# Projeto Torre

*(nome provisório)*

Roguelite de ação, exploração e economia: suba uma torre de 10 andares cumprindo demandas diárias crescentes de Monster Essence, evoluindo arma, economia e um time de employees ao longo da run.

📖 **Documentação completa:** https://luciano-claudio.github.io/MonsterLLC/

## Unity

Versão exata: **6000.0.35f1 LTS** (template URP 2D).

## Quickstart

```
git lfs install       # só na primeira vez nesta máquina
git clone https://github.com/Luciano-Claudio/MonsterLLC.git
```

Abra a pasta clonada pelo Unity Hub, selecionando a versão **6000.0.35f1 LTS** do Editor. Passo a passo completo (instalação do Editor, LFS, primeira abertura, build local): [Project Setup Guide](docs/guides/project-setup.md).
